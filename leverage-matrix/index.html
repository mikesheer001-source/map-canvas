How to read the returns — Each ticker displays its own measured return for the selected holding period. The calculations use available historical daily closing prices; no value is inferred by multiplying the stock return by leverage. A dash means data is unavailable or the fund did not exist for the whole period.
Adjusted vs. price returns — Adjusted-close returns account for splits and historical distributions when available from the data feed. Price returns exclude cash distributions. WeeklyPay funds (1.2×) pay frequent distributions, so price-only comparisons can be especially misleading. The 1.5–2× product is an income strategy, not a fixed multiplier.
Market and data caution — The 3× instruments are European exchange-traded products, not U.S. ETFs; some have multiple listings/currencies. Figures are end-of-day, delayed and indicative, not a live quote. Data provider: Yahoo Finance chart history (unofficial). Missing or stale data is labeled, not guessed.
Auto-refreshed by a scheduled GitHub Actions workflow when available. Click a ticker to inspect the historical window and data source. Daily-reset leverage compounds over time and can diverge substantially from its advertised multiplier. Not investment advice.
